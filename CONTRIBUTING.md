# Como contribuir

Contribuições são bem-vindas, especialmente correções de precisão, clareza, acessibilidade e links oficiais atualizados.

1. Faça um fork e crie uma branch com nome descritivo, por exemplo `docs/atualiza-csf`.
2. Escreva em português do Brasil e mantenha o escopo dos guias. Não copie grandes trechos de normas ou materiais protegidos.
3. Ao acrescentar informação normativa, inclua a fonte primária e, quando aplicável, edição, versão ou data de consulta.
4. Verifique links relativos, títulos Markdown e consistência dos índices.
5. Abra um pull request descrevendo o motivo da alteração, os arquivos afetados e as verificações realizadas.

Não inclua credenciais, dados pessoais, conteúdo confidencial ou instruções que facilitem o uso não autorizado de sistemas. Alterações em fontes oficiais devem ser descritas como referência, não como endosso.
